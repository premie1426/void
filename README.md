# VOID – VS Code Theme

A custom dark, modern theme for Visual Studio Code.

![VOID Theme Preview]()

---

## Installation from VSIX

1. Download the `void-1.0.1.vsix` file.
2. Open **VS Code**.
3. Press `Ctrl+Shift+P` (or `Cmd+Shift+P` on macOS) to open the Command Palette.
4. Select **Extensions: Install from VSIX…**
5. Choose the `.vsix` file you downloaded.

Once installed, activate it via **File → Preferences → Color Theme** and select **VOID**.
